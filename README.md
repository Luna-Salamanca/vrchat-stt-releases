# VRChat Speech-to-Text: downloads

Ready-to-run Windows builds of VRChat Speech-to-Text. Speech-to-text for the VRChat chatbox over OSC, with local Whisper on the GPU and a SteamVR wrist overlay.

Download `vrchat-stt.exe` from the [latest release](../../releases/latest) and run it. It's a single file, and nothing needs installing.

The app updates itself. In **Settings → Updates** you can install the newest version with one click, or go back to an older one. Each release includes `vrchat-stt.exe.sha256`, which the app checks before replacing itself.
